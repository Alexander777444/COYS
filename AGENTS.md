# Agent Rules

- Language: JavaScript ES Modules, classes for controllers/services/repositories.
- Architecture: Route -> Controller -> Service -> Repository -> PostgreSQL.
- All code and comments in English.
- Work one task at a time; do not add features that were not requested.
- Never commit secrets; never run `git push`.
- Database is Supabase used ONLY as PostgreSQL via the pg driver. Do NOT use supabase-js or Supabase's auto-generated API.
